# Team Roles - AI/Quality Sentinel

This project requires a multidisciplinary team with specific expertise. Below is an overview of how each professional can contribute to the project's success.

## 👥 Available Roles

### 1. **[Product Owner (PO)](product-owner.md)**
Defines product vision, manages backlog priorities, and ensures alignment with business goals.

### 2. **[Scrum Master (SM)](scrum-master.md)**
Facilitates agile ceremonies, removes blockers, and ensures the team follows agile practices.

### 3. **[Quality Assurance (QA)](qa.md)**
Ensures code quality, test coverage, and validates that requirements are met before deployment.

### 4. **[Backend Developer (.NET Specialist)](backend-dotnet.md)**
Designs and implements backend services, APIs, and business logic using .NET technologies.

### 5. **[Frontend Developer (React/Angular Specialist)](frontend-react-angular.md)**
Builds user interfaces and ensures responsive, intuitive user experiences.

### 6. **[Additional Specialists](additional-specialists.md)**
DevOps, Data Engineers, Security Specialists, and other roles as needed.

- **How to Help:** Specific ways to contribute to AI/Quality Sentinel
- **Key Responsibilities:** Main tasks and deliverables
- **Required Skills:** Technical and soft skills needed
- **Experience Level:** Minimum experience recommended
