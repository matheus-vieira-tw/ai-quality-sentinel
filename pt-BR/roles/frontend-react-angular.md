# Desenvolvedor Frontend (Especialista React/Angular)

## Visão Geral

O Desenvolvedor Frontend (Especialista React/Angular) constrói interfaces de usuário e garante experiências de usuário responsivas e intuitivas. No AI/Quality Sentinel, a equipe frontend cria o dashboard onde times visualizam resultados de análise, gerenciam tickets e interagem com o sistema de governação de qualidade.

---

## Como Ajudar o Projeto

### 1. **Construir Dashboard de Análise**
- Criar dashboards interativos para exibir resultados de análise de IA
- Construir visualizações para métricas de qualidade e tendências
- Implementar filtragem e ordenação de resultados de análise
- Criar views detalhadas de relatórios para stakeholders

### 2. **Desenvolver UI de Gerenciamento de Tickets**
- Construir interfaces para navegar e gerenciar tickets do Jira
- Implementar views de detalhe de ticket com análise de código vinculada
- Criar formulários para atualizações de ticket e avaliações de qualidade
- Construir fluxos para triagem e resolução de tickets

### 3. **Implementar Features Amigáveis ao Usuário**
- Criar componentes para navegação de recomendações de IA
- Construir sistemas de notificação e alertas
- Implementar capacidades de busca e filtragem
- Projetar layouts responsivos para dispositivos móveis e computadores

### 4. **Integrar com APIs Backend**
- Conectar frontend com APIs backend para recuperação de dados
- Implementar state management para fluxos de dados complexos
- Tratar erros de API com elegância e retorno ao usuário
- Otimizar chamadas de API para desempenho

### 5. **Garantir Qualidade de Código e Performance**
- Escrever código maintível e baseado em componentes
- Implementar testes unitários e de integração para componentes
- Otimizar tamanho de bundle e tempos de carregamento
- Implementar padrões de acessibilidade (WCAG)

---

## Competências Necessárias

**Técnicas:**
- Experiência expert-level em React ou Angular (escolha um como principal, aprenda o outro se necessário)
- Proficiência em TypeScript/JavaScript
- CSS/SCSS e design responsivo
- State management (Redux, NgRx, Zustand, ou Context API)
- Integração de API e clientes HTTP
- Frameworks de teste (Jest, Mocha, Jasmine)
- Git e controle de versão

**Soft Skills:**
- Conscientização de UX/UI e empatia com usuários
- Comunicação com desenvolvedores backend em contratos de API
- Skills de resolução de problemas e debugging
- Atenção aos detalhes
- Disposição para colaborar em decisões de projeto

---

## Nível de Experiência

**Mínimo:** 3-4 anos de experiência em desenvolvimento frontend
**Ideal:** 5+ anos com React ou Angular, com experiência em dashboards complexos e visualização de dados
