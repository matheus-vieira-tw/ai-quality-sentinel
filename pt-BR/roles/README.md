# Papéis da Equipe - AI/Quality Sentinel

Este projeto requer uma equipe multidisciplinar com expertise específica. Abaixo está uma descrição detalhada de cada papel necessário para o sucesso do projeto.

## 📋 Papéis Necessários

### 1. **[Product Owner (PO)](product-owner.md)**
Define a visão do produto, gerencia prioridades do backlog e garante alinhamento com objetivos de negócio.

### 2. **[Scrum Master (SM)](scrum-master.md)**
Facilita cerimônias ágeis, remove bloqueadores e garante que a equipe siga práticas ágeis.

### 3. **[Quality Assurance (QA)](qa.md)**
Garante qualidade do código, cobertura de testes e valida que requisitos sejam atendidos antes da implantação.

### 4. **[Desenvolvedor Backend (Especialista .NET)](backend-dotnet.md)**
Projeta e implementa serviços backend, APIs e lógica de negócio usando tecnologias .NET.

### 5. **[Desenvolvedor Frontend (Especialista React/Angular)](frontend-react-angular.md)**
Constrói interfaces de usuário e garante experiências de usuário responsivas e intuitivas.

### 6. **[Especialistas Adicionais](additional-specialists.md)**
DevOps, Engenheiros de Dados, Especialistas em Segurança e outros papéis conforme necessário.
