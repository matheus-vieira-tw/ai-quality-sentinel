# Project Overview: AI/Quality Sentinel (AI/QS)

## 1. O Problema
A falta de qualidade em projetos de software muitas vezes não é uma falha técnica, mas uma falha de **contexto**. 
- **Gaps de Entendimento:** Requisitos vagos no Jira geram código que não atende ao negócio.
- **Falta de Consistência:** Prazos apertados levam à negligência de boas práticas.
- **Sobrecarga de Revisão:** Revisores humanos (Tech Leads/Seniors) perdem tempo com sintaxe e esquecem de validar se a regra de negócio do ticket foi realmente cumprida.

## 2. A Solução
O **AI/Quality Sentinel** é um agente de governação inteligente que atua como uma ponte entre a gestão (Jira) e a execução (GitHub/GitLab). Ele analisa o "triângulo da qualidade":
1. **Intenção:** O que o ticket diz.
2. **Execução:** O que o código faz.
3. **Padrão:** O que as boas práticas da Thoughtworks exigem.

## 3. Objetivos Principais
- Reduzir o retrabalho em 30% ao identificar desalinhamentos antes do merge.
- Melhorar a saúde do backlog através da análise de qualidade das histórias de usuário.
- Transformar o desenvolvedor num "Revisor Estratégico", delegando a análise minuciosa de padrões à IA.

## 4. Diferencial AI/works™
A solução utiliza a infraestrutura segura da TW para garantir que dados sensíveis de clientes e códigos proprietários sejam processados sob rigorosos padrões de privacidade.

## 5. Modelo de Equipe para Hackathon (até 3 pessoas)
- **Pessoa 1:** Produto e priorização (PO + SM)
- **Pessoa 2:** Desenvolvimento generalista focado em implementação core e integrações
- **Pessoa 3:** Desenvolvimento generalista focado em implementação core e QA prático
